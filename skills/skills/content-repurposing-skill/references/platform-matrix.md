## Character Limits by Platform

| Platform | Max Chars | Notes |
|----------|-----------|-------|
| X/Twitter | 280 | Hard limit, truncated if exceeded |
| LinkedIn | 3000 | Longer posts get hidden behind "see more" |
| Instagram | 2200 | Display limit, actual limit is 2200 |
| Facebook | 63206 | Very generous, but shorter is better |
| TikTok | 150 (desc) | Description only, video is main content |
| YouTube | 5000 | Description field |
| Threads | 500 | Casual, conversational |
| Bluesky | 300 | Direct, authentic |
| Mastodon | 500 | Friendly, community |
| Pinterest | 500 | How-to, aspirational |
| Google BP | 1500 | Local, helpful |

## Tone Guide

| Platform | Primary Tone | Avoid |
|----------|-------------|-------|
| X/Twitter | Punchy, clever | Corporate jargon |
| LinkedIn | Professional, story-driven | Overselling |
| Instagram | Inspiring, aesthetic | Long text |
| Facebook | Conversational, personal | Clickbait |
| TikTok | Energetic, trendy | Stiff delivery |
| YouTube | Educational, detailed | Fluff |
| Threads | Casual, chatty | Promotional |
| Bluesky | Direct, authentic | Over-hashtagging |
| Mastodon | Respectful, community | Self-promotion |
| Pinterest | Aspirational, actionable | Generic descriptions |
| Google BP | Local, helpful | Overly promotional |
